# SQL Learning & Practice

A structured SQL learning and practice repository documenting my progression from foundational queries to more advanced data analysis techniques. This repository includes hands-on exercises, query solutions, explanations, and practical projects designed to strengthen my SQL skills in data analysis, database querying, and problem-solving.

## Repository Goals

- Build a strong foundation in SQL and relational databases.
- Practice SQL concepts through structured exercises and coding challenges.
- Document query solutions and explain the reasoning behind them.
- Apply SQL to practical business questions and data analysis problems.
- Develop a portfolio demonstrating my ability to use SQL to solve real-world problems.

## Repository Structure

| Folder | Focus |
|---|---|
| `00-learning-roadmap/` | Learning objectives, progress tracking, and SQL reference material |
| `01-sql-fundamentals/` | Basic querying, filtering, sorting, and limiting results |
| `02-aggregations/` | Aggregate functions, grouping, and conditional aggregation |
| `03-joins/` | Combining related data across tables |
| `04-intermediate-sql/` | Conditional logic, subqueries, CTEs, set operations, and useful functions |
| `05-window-functions/` | Ranking, partitioning, running totals, and other window calculations |
| `06-practical-projects/` | SQL projects answering practical questions using data |
